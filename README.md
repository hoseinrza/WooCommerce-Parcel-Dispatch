# WooCommerce Parcel Dispatch

ثبت خروج مرسولات انبار با اسکن بارکد پستی ذخیره‌شده در متای `post_barcode` سفارش‌های ووکامرس.

افزونه فقط متای `post_barcode` را می‌خواند و هرگز آن را نمی‌سازد، تغییر نمی‌دهد یا بازنویسی نمی‌کند. هر خروج در جدول اختصاصی `{prefix}wcpd_dispatches` با بارکد یکتا، اپراتور و زمان UTC ثبت می‌شود و یک یادداشت خصوصی روی سفارش می‌گذارد.

## نیازمندی‌ها

- WordPress 6.4 یا بالاتر
- WooCommerce 8.0 یا بالاتر (سازگار با HPOS)
- PHP 8.2 یا بالاتر

## سازگاری با اسکنر بارکد

افزونه برای **اسکنرهای استاندارد USB و بلوتوث در حالت HID Keyboard** ساخته شده است:

- اسکنر مثل صفحه‌کلید تایپ می‌کند و ورودی در یک `<input type="text">` معمولی دریافت می‌شود. به WebUSB، WebHID یا درایور اختصاصی نیازی نیست.
- پسوند **Enter (CR)** و **Tab** هر دو پشتیبانی می‌شوند. Tab فقط وقتی به‌عنوان پایان اسکن مصرف می‌شود که ورودی خالی نباشد؛ Tab روی ورودی خالی رفتار عادی جابه‌جایی فوکوس را حفظ می‌کند تا رسیدن با کیبورد به دکمهٔ تأیید ممکن بماند.
- فیلد بارکد هنگام بارگذاری صفحه فوکوس می‌گیرد و بعد از جست‌وجوی موفق، خطا، لغو و ثبت خروج دوباره فوکوس و انتخاب می‌شود.
- پس از هر اسکن ورودی پاک می‌شود و اسکن بعدی بلافاصله امکان‌پذیر است. تا زمانی که یک درخواست در جریان است، Enter تکراری درخواست جدید نمی‌سازد.
- بارکد به‌صورت رشته پردازش می‌شود؛ صفرهای ابتدایی و نویسه‌های بارکد حفظ می‌شوند.
- اسکن فقط سفارش را پیدا و نمایش می‌دهد. **ثبت خروج هرگز خودکار انجام نمی‌شود** و فقط با تأیید صریح اپراتور (کلیک یا Tab و Enter روی دکمهٔ تأیید) ثبت می‌شود.

### حالت‌های خارج از پشتیبانی

اسکنرهایی که در حالت **سریال (RS-232)**، شبکه یا با **پروتکل اختصاصی سازنده** کار می‌کنند در حالت HID Keyboard نیستند و ممکن است به یکپارچه‌سازی جداگانه نیاز داشته باشند؛ برای نمونه یک پل نرم‌افزاری محلی که داده را به ورودی صفحه‌کلید یا یک endpoint مجاز تبدیل کند. این افزونه عمداً به WebUSB/WebHID یا SDK سازنده وابسته نیست.

## API

همهٔ مسیرها زیر `wcpd/v1` ثبت شده‌اند و به ورود، nonce و capability نیاز دارند (پیش‌فرض `manage_woocommerce`، قابل تغییر با فیلتر `wcpd_dispatch_capability`).

- `POST /wcpd/v1/barcode/lookup` — یافتن سفارش با بارکد
- `POST /wcpd/v1/dispatch` — ثبت خروج با اعتبارسنجی مجدد بارکد و شناسهٔ سفارش
- `GET /wcpd/v1/dispatches` — تاریخچهٔ صفحه‌بندی‌شده با فیلتر بارکد، سفارش و اپراتور

وضعیت‌های مجاز خروج به‌صورت پیش‌فرض `processing` و `completed` هستند و با فیلتر `wcpd_dispatch_allowed_order_statuses` تغییر می‌کنند.

## تست‌ها

تست‌های PHP روی MariaDB و WordPress test suite اجرا می‌شوند:

```bash
bash tests/bin/phpunit.sh
```

تست‌های جاوااسکریپت اسکریپت واقعی را در jsdom با `wp.apiFetch` تقلبی اجرا می‌کنند:

```bash
npm ci
npm run test:js
```
